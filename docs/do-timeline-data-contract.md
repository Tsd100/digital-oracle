# DO 历史时间线数据契约

原始报告保持不变。索引以 UTF-8 正文 SHA-256 识别逻辑报告，以 `sources` 保存每个项目、归档和 Web 历史入口。相同内容只展示一份，仍保留所有来源位置。

`analysis_at` 只接受正文明确的分析时间，使用北京时间 ISO 8601；文件名及修改时间不能代替。未知时间列为“待核对”，不参与相邻报告比较。`data_as_of` 是原文数据口径，`market_session` 为盘中、收盘或未知。`horizon` 是报告明确的预测窗口。

`subjects` 来自标题或结论，允许一份报告有多个主题；联合主题的总论不能自动代表其中任一标的。`summary`、`scenarios`、`thresholds` 保存原话、概率和阈值。主情景概率仅在窗口一致、情景语义一致且报告非联合主题时计算差值。

抽取质量为 `confirmed` 或 `needs_review`。人工校正存在独立表及变更日志，不覆盖原文或机器抽取内容。可查看完整哈希和原文定位后，使用 CLI 的 `correct` 命令修订单个字段。
